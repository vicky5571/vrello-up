# Specs Directory

Design specifications for all features in vrello-up.

## Naming Convention

```
YYYY-MM-DD-<feature-slug>-design.md
```

## Required Sections (per spec)

1. Executive Summary
2. UX Flow
3. SSOT Schema changes (`src/types/index.ts`)
4. SQL / Prisma schema changes
5. Pure logic function signatures
6. API contracts (method, path, request, response)
7. Acceptance Criteria (checkbox list)
8. Non-Goals
9. Verification Checklist
